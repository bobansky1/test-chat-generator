# Chat Studio

Редактор макетов переписок Telegram в оформлении iPhone. React 19 + TypeScript + Vite. Данные и фотографии хранятся локально в IndexedDB браузера, сервер и аккаунт не нужны.

## Запуск

Требуется Node.js 24. Страница создания диалогов находится на `/`. Старый адрес `/app` перенаправляет на неё.

```sh
npm install
npm run dev
```

Открыть адрес, выведенный Vite (обычно http://127.0.0.1:5173).

```sh
npm run build    # проверка TypeScript и production-сборка в dist/
npm run preview # просмотр сборки
npm test        # проверки формата импорта
```

## Возможности

- Кнопка «Загрузить JSON», перетаскивание файла и вставка JSON. JSON создаётся вне приложения.
- Проверка полей с указанием номера ошибочного сообщения; образец JSON и инструкция для ИИ в разделе «Формат JSON».
- Профиль собеседника, аватар, статус, верификация и закреплённое сообщение.
- Входящие/исходящие сообщения, фото, визуальные голосовые, даты, цитаты, реакции, время и галочки.
- Редактирование по нажатию на сообщение, изменение порядка, удаление, отмена/повтор до 40 действий.
- Светлая/тёмная темы, фоны, время iPhone, Wi-Fi/5G/LTE, сигнал, батарея, зарядка, беззвучный режим и Dynamic Island.
- Плавающие стеклянные панели с размытием и SVG-иконки. Во вкладке «Экран» доступен пресет «Стиль как на референсе» с тёмным фоном и фиолетовыми сообщениями. Эффект стекла сохраняется в PNG и HTML.
- PNG экрана или всей переписки, 1×/2×/3×; HTML с встроенными фото; JSON со всеми ресурсами.
- Повторный импорт собственного HTML без выполнения кода из него.
- Адаптивная панель редактора и автосохранение в браузере.

## Формат JSON

Полный пример: `public/chat-example.json`. Минимальный файл:

```json
{
  "chat": { "name": "Александра", "status": "в сети" },
  "messages": [
    { "sender": "other", "text": "Привет!", "time": "10:24" },
    { "sender": "me", "text": "Привет! 👋", "time": "10:25", "status": "read" }
  ]
}
```

Можно передать просто массив сообщений. Необязательные параметры получают значения по умолчанию.

Для закреплённого сообщения используйте `chat.pinned`. Параметры `screen.muted: true` и `screen.wallpaper: "violet"` включают значок беззвучного режима и фиолетовый фон.

| Поле сообщения | Значения |
| --- | --- |
| `id` | Необязательный уникальный идентификатор |
| `type` | `text` (по умолчанию), `photo`, `voice`, `date`, `emoji`, `round` |
| `sender` | `me` (справа), `other` (слева, по умолчанию) |
| `text` | Текст сообщения / подпись / текст разделителя даты |
| `time` | ЧЧ:ММ, по умолчанию 10:00 |
| `status` | `sent`, `delivered`, `read` (по умолчанию) |
| `image` | Имя загружаемого файла или растровый data URL |
| `reply` | Текст цитируемого сообщения |
| `reaction` | Эмодзи |
| `duration` | Визуальная длительность голосового, например 0:12 |

Фотографии `photo.jpg` и аватар `avatar.jpg` загрузите в «Медиатеку» с совпадающими именами. Повторная загрузка того же имени заменяет ресурс. Сохранённый JSON включает изображения в `assets`, повторно загружать их не нужно. Удаление ресурса из медиатеки оставляет ссылку в сообщении: загрузите файл снова или удалите сообщение. Удаление можно отменить в редакторе.

## Экспорт и ограничения

В режиме «Экран iPhone» PNG/HTML содержит текущую видимую область прокручиваемого диалога, включая строку состояния и нижнюю панель. «Вся переписка» создаёт длинное изображение/страницу. Рамка устройства и выделение редактируемого сообщения не экспортируются.

- Размер экрана — 393 логических пикселя по ширине. Это стилизация iOS, не нативное приложение и не гарантия попиксельного совпадения со всеми версиями Telegram/iPhone. На Windows используется системный шрифт; emoji зависят от ОС.
- Голосовые сообщения визуальные, воспроизведения/записи аудио нет.
- PNG — экспорт, не распознавание чужих скриншотов. В HTML можно импортировать только файлы, созданные этим редактором.
- 1000 сообщений, 10 000 символов на сообщение; файл изображения до 10 МБ и 40 Мп, автоматически уменьшается до 1800 px по длинной стороне. GIF сохраняется как статичный кадр.
- Общий объём медиатеки до 50 МБ; JSON до 60 МБ. Очень длинные PNG ограничены высотой 16 000 физических px: используйте 1× или HTML.
- Удалённые URL изображений не загружаются. Используйте локальные файлы: это сохраняет автономность и предотвращает проблемы CORS при экспорте.
- Автосохранение привязано к адресу сайта и профилю браузера. Очистка данных браузера удалит его. JSON — переносимая резервная копия проекта.

## Структура

`src/App.tsx` — редактор; `Phone.tsx` и `phone.css` — экспортируемый экран; `Icons.tsx` — SVG-иконки; `model.ts` — формат и валидация; `export.ts` — PNG/HTML; `storage.ts` — IndexedDB.

Экспорт PNG, HTML и JSON бесплатный, без ключей и ограничений на число скачиваний. Файлы создаются в браузере.

Для размещения: выполните `npm run build` и опубликуйте каталог `dist` на статическом хостинге. Либо запустите `npm start` для раздачи сборки на порту 3001 (порт можно задать переменной `PORT`).


Свой фон Telegram: во вкладке «Экран» нажмите «Загрузить свой фон». Фото заполняет фон переписки и сохраняется в PNG, HTML, JSON и автосохранении. В JSON поле `screen.wallpaperImage` содержит имя ресурса из `assets` или растровый data URL.
Во вкладке «Экран» доступны отдельные градиенты входящих и исходящих сообщений: готовые варианты, два цвета, цвет текста и направление. Текст поля ввода можно заменить своим. При прокрутке вверх появляется кнопка перехода к последним сообщениям.
Отдельное сообщение «Эмодзи» отображается крупно без пузыря. В редакторе есть панель эмодзи и форматирование выделенного текста: **жирный**, *курсив*, __подчёркивание__, ~~зачёркивание~~ и `моноширинный`. Оформление сохраняется при экспорте и повторном импорте JSON/HTML. Эмодзи отображаются локальными изображениями Apple 160×160 из https://github.com/rmdashrfv/emoji-datasource. HTML-экспорт встраивает изображения и работает автономно.
Цитата оформляется кнопкой ❞ (в JSON: >>>цитата>>>), спойлер / скрытый текст — кнопкой ◌ (||текст||). Спойлер раскрывается нажатием или Enter/пробелом в предпросмотре и автономном HTML. PNG сохраняет текущее состояние видимости.

Сборка использует относительные пути к ресурсам и может размещаться в подпапке. Публикуйте весь каталог dist вместе с assets; при обновлении сначала загрузите новые assets, затем index.html. Не удаляйте старые хешированные ресурсы, пока у пользователей может быть открыта предыдущая версия.

После сборки `npm run check:build` проверяет по HTTP все файлы эмодзи при размещении в корне и подпапке.

Кружки: в «Сообщениях» нажмите «◉ Кружок», загрузите фото и задайте длительность (М:СС), отправителя и время. Доступно добавление из медиатеки. Это статичный кадр с круглой обрезкой по центру, значком выключенного звука и галочками. В JSON: type: "round", image: "photo.jpg", duration: "0:03". Изображение сохраняется в assets и переносится в PNG/HTML/JSON; видео и аудио не используются.

Исходные файлы лендинга, блога, SEO и оплаты сохранены для дальнейшего использования. Текущий редактор их не подключает. Команда npm test запускает проверки текущего редактора; прежние тесты SEO и оплаты сохранены отдельно в tests/content.test.ts и tests/billing.test.mjs.
